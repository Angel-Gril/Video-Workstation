# AI Video Workstation

一个统一的开源智能视频创作工作台：素材导入、语义理解、叙事重剪、多轨编辑、语音生成与导出在同一个项目与同一套命令层中协作。

## 设计原则

- 人类编辑与 AI 编辑共享同一条命令路径，所有修改都是可回放、可撤销、可审计的命令。
- 项目文件是一个可迁移的工作目录，媒体、转写、叙事、时间线与导出产物保持同一事实源。
- 浏览器内推理用于低延迟辅助，重处理任务交给本地服务进程。
- 时间线是不可变状态，命令只生成新状态，渲染导出由命令行媒体工具作为最终依据。

## 当前阶段

已完成核心时间线内核、关键帧采样、剪辑校验、媒体探测管线、统一命令层和工作站界面。

主工作区包含三栏：素材/信号/意图区、预览与时间线区、方案审核/属性/导出区。
素材库支持本地媒体导入、移除、单独分析与快速加入时间线；语音转写和场景检测结果可以定位预览，
场景可以直接加入时间线；语音结果可以一键转成字幕轨。

AI 方案器结合目标、时长、语音密度、场景变化、视觉亮度/饱和度/运动代理信号和用户意图生成可解释候选片段，
支持均衡、视觉优先、叙述优先三种策略切换和逐段采纳/拒绝。时间线提供多轨显示、
缩放、拖拽移动、首尾裁剪、拆分、删除、轨道静音/隐藏/锁定、视频缩略图条、音频波形条、
解说字幕覆盖预览和播放头定位。右侧属性面板支持字幕编辑、解说文本、淡入/淡出/叠化转场、
透明度、移动和跨轨移动；导出设置可选择画质、分辨率、帧率和输出文件。

左侧解说支持本地 edge-tts 生成中文语音，可选择声音、语速和混音避让；生成的语音与
文本一起作为可撤销的音频片段进入项目。AI 方案会根据片段来源和意图生成解说草稿，
应用方案时自动合成解说并加入时间线。导出端会按解说片段对背景音执行逐帧避让，
同时渲染片段转场。解说片段仍会在预览中作为字幕覆盖层显示。视觉信号来自本地抽帧
代理分析，不要求外部模型密钥；它是方案器的辅助维度，不是完整视觉语义理解。

导出端支持关键帧驱动的逐帧缩放、位移、旋转、亮度、对比度和饱和度。透明度导出目前
取首个关键帧值，这是本地 FFmpeg 快速路径的保守限制；后续会补上基于 alpha 蒙版的
逐帧透明度渲染。

## 开发验证

```bash
npm run typecheck
npm test -- --run
```

启动前需要让 Python 进程能找到 FFmpeg。Windows 本机示例：

```powershell
$env:FFMPEG_PATH = "$env:LOCALAPPDATA\Microsoft\WinGet\Links\ffmpeg.exe"
$env:FFPROBE_PATH = "$env:LOCALAPPDATA\Microsoft\WinGet\Links\ffprobe.exe"
npm run dev
```

启动 `npm run dev` 后，端到端链路已在 7 分 28 秒 / 1080p 本地视频上验证：导入素材 ->
语音/场景/视觉分析 -> 生成并应用 AI 方案 -> 保存并重载项目 -> 时间线裁剪与撤销 ->
异步导出 30 秒 MP4。

当前端到端脚本进一步验证逐段审核、方案应用、保存重载、时间线裁剪和撤销恢复。
服务级导出验证覆盖位移和缩放关键帧动画，并确认产物按帧变化。TTS、波形、缩略图、
解说混音与视觉信号接口已通过本机素材检查；方向型 wipe/slide 转场已加入 UI。
